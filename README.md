# Fashion-MNIST Classification with Neural Networks

A coursework project focused on comparing different neural network architectures for image classification using the **Fashion-MNIST** dataset.

## 📌 Project Overview

The goal of this project is to classify Fashion-MNIST images and compare the performance of several neural network architectures.

The following models were tested:

- Baseline Dense Neural Network
- Improved Dense Neural Network with GELU activation
- Convolutional Neural Network (CNN)

## 🛠 Technologies

- Python
- TensorFlow
- Keras
- NumPy
- Matplotlib
- Fashion-MNIST

## 🔍 Approach

1. Load and prepare the Fashion-MNIST dataset
2. Build a baseline Dense neural network
3. Improve the Dense architecture
4. Build and train a CNN
5. Evaluate all models on test data
6. Compare their performance

## 📈 Results

- Baseline Dense model accuracy: approximately **86.24%**
- CNN test accuracy: **92.16%**

The CNN achieved the best performance among the tested models.

## 💡 Conclusion

Increasing the complexity of the Dense network produced only a modest improvement.

The CNN performed better because convolutional layers are able to capture spatial structure and local patterns in images.
